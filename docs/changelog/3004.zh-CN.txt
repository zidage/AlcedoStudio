Alcedo Studio 0.3.2（构建 3004）

从 0.3.1 或更早版本升级前须知
-----------------------------
- 柔焦滤镜采用了新的高光曲线。使用此滤镜的旧照片在升级后可能会有所不同：接近白色的
  区域周围的光晕更柔和，不再出现生硬的边缘。

本构建新功能
------------
- 导出会记住上次使用的导出文件夹，重启后依然有效。如果该文件夹已不存在，则改用“图片”
  文件夹。“浏览”会在当前文件夹中打开。
- Windows：启动 Alcedo Studio 时不再弹出控制台窗口。

本构建编辑器修复
----------------
- 在滑块调整或蒙版编辑尚未结束时，撤销、重做、历史记录跳转和粘贴将不可用。此前，
  未完成的数值可能被带入导出、缩略图和保存结果。
- 关闭图像时选择“放弃”，现在会真正丢弃编辑。此前，这些编辑可能在下次打开该图像时
  重新出现。
- 从编辑器返回图库后，点击关闭（X）会立即退出应用，即使缩略图仍在生成中。

本构建其他修复
--------------
- JPEG 等位图图像：打包的 macOS 版本不再因缺少 Metal 库而无法处理；使用 OpenCL 的
  Windows 安装版本也不再因缺少源文件而处理失败。
- macOS：包含中文语义标签的项目不再因“Invalid unicode”错误而无法打开。以某些带重音
  字母结尾的相机和镜头名称也不再被截断。
- 使用小数逗号的系统（例如德语）：.cube LUT 数值可以正确读取，f/2.8 等搜索词会保留
  小数部分，镜头名称也使用小数点显示。
- 语义标签现在以与语言无关的统一形式存储。旧项目会在打开时自动转换一次。标签搜索、
  分组和统计与之前一致，输入“沙漠”等中文搜索词仍能找到对应照片。
- 图库：更改选择或从编辑器返回后，网格卡片不再保持空白。
- 没有相机色彩矩阵的尼康 NEF 文件（例如 Z50 II 拍摄的文件）现在可以作为 RAW 导入。
- 导出或缩略图渲染失败时，现在会立即释放所占用的 GPU 显存。

0.3.2 新功能
------------
- JPEG、PNG、TIFF 和 OpenEXR 图像：可以像 RAW 照片一样导入和编辑。Alcedo Studio
  会读取文件内嵌的色彩配置文件，并将图像转换到 ACES 工作流程中。OpenEXR 以及 PQ 或
  HLG 图像会被标记为 HDR。文件的读取方式由文件内容决定，而不是扩展名。
- 位图输入色彩：对于这些图像，RAW 面板会显示输入色彩和输入配置文件菜单，取代白平衡和
  RAW 解码设置。
- 文件夹导入文件类型：新增“文件类型”一行，可选择 RAW、JPEG、TIFF、PNG 或 OpenEXR，
  并显示每种类型的文件数量。导入只包含所选类型，且会记住所选内容。其他类型的文件会被
  计数并显示为已排除。
- LUT 输入与输出编码：可选择 LUT 期望的输入色彩编码和它输出的编码，包括场景编码
  （相机 Log 曲线和 ACES）和显示编码（sRGB、BT.1886、PQ、HLG 等）。显示编码输出会
  通过 ACES 2.0 逆向输出变换转回场景。每次更改记为一步历史记录。
- 为此 LUT 记住：LUT 库可以为单个 LUT 保存一组编码，并在每次使用该 LUT 时自动应用。
  官方 LUT 包默认使用 ACEScc。调整的复制和粘贴也包含 LUT 编码。
- 图库编辑时间：可按最后编辑时间排序，或按编辑日期分组，未编辑的照片单独成组。打开
  项目时，图库会定位到上次编辑的照片。

0.3.2 改进
----------
- 后台任务：底部任务栏改为顶部工具栏中的小状态灯。任务运行或出错时会展开显示详情，
  短暂的任务不再让任务栏闪现。点击状态灯可展开或收起。
- LUT 浏览器：筛选侧边栏改为顶部一行“类别”“来源”“品牌”“印放胶片”筛选框，每个
  筛选框只列出有匹配 LUT 的值。“印放胶片”新增“无印放胶片”选项。用户 LUT 归入“用户”
  类别，并有提示显示存放自定义 LUT 的文件夹。浏览器会滚动到已应用的 LUT，底栏会显示
  其名称。
- “设置 > LUT”现在可以在确认后移除已安装的官方 LUT 包。使用其中 LUT 的照片会失去该
  效果，直到重新安装。
- 警告和错误信息改用白字红底徽标，更易阅读。
- “设置”的类别列表现在可以滚动，包括“关于”在内的所有类别都可访问。

0.3.2 修复
----------
- 图库：折叠或展开分组时不再跳回顶部，从编辑器返回后分组视图会保持原来的位置。按
  分组字段排序时，分组本身也会随之排序。
- OpenCL：修复了在应用 LUT 时调整白平衡可能导致的崩溃。同时，图像上传到 GPU 的速度
  也更快了。
- 调整下拉菜单中较长的标签不再被截断。
