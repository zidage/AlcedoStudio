Alcedo Studio 0.3.5

升级前须知
----------
- 本版本移除“高级内容分析”，项目中已有的分析结果仍会保留。请在“设置 > 已保存的
  AI 密钥”中删除该功能保存的 API 密钥，并断开 Codex 登录。这个清理页面仅在本版本
  保留，下一版本将移除。

新功能
------
- 胶片印片：新增 30 款负片和 5 款彩色反转片模拟，胶片浏览器支持搜索、品牌筛选和色卡。
  负片可以搭配摄影相纸和电影印片胶片，包括独立的 Cine Look (2383) 风格；反转片以
  灯箱观看方式呈现。印片和反转片输出为 Rec. 709 SDR。面板会记住上次使用的胶片设置，
  控件按折叠分组排列，并提供说明。CUDA、OpenCL 和 Metal 均支持胶片流程，所需胶片
  数据随安装包提供。alcedo-cli 新增 film.list，可为脚本编辑和渲染选择胶片。
- 负片扫描：通过虚拟扫描器读取并反转模拟负片，再用 OpenDRT 输出 SDR 或 HDR。
  可以调整扫描曝光、对比度、青品黄、黑位及虚拟扫描器参数。新的扫描设置默认启用
  50% 强度的“中性”自动校色，缩放和平移时保持全画面的色彩平衡。“场景光”默认使用
  “按拍摄参数”，印片、扫描和反转片均会读取 RAW 白平衡的色温与色调。
- 片幅与颗粒：新增 16mm、35mm 和 70mm 片幅。颗粒大小随片幅和图像尺寸变化，胶片印片
  使用所选胶片的颗粒度数据；较小片幅也会放大胶片印片中的光扩散和光晕。颗粒强度范围
  扩展为 0 至 200%，缩放时保持颗粒尺度一致。胶片印片在印片或扫描前将颗粒加入胶片层。
  切换到胶片印片时，若颗粒强度为零则启用 100%；切换到其他方法时清零。其他显示变换
  方法仍在“后期处理”中提供颗粒控件。
- 影集与浏览：影集改为紧凑的层级树，支持就地新建和重命名、拖动移动、键盘操作，以及
  随照片变化更新的照片数量。照片菜单的“添加到”子菜单包含导出队列和可滚动的影集树，
  影集较多时可筛选。在编辑器中，无需按 Ctrl 即可用鼠标滚轮围绕光标缩放；触控板滚动
  仍用于平移画面。

修复
----
- 镜头校正与图像加载：畸变和色差校正改用 Lanczos-3 重采样，保留更多细节，并限制亮边
  附近的振铃。改进 Panasonic RW2 文件，以及通过镜头 ID 识别的 Nikon 镜头的自动匹配。
  修复内嵌 ICC 配置同时包含 LUT 表和色彩描述标签时 HDR TIFF 加载失败的问题，包括
  受影响的 Hasselblad X2D II 文件。
- 大项目与保存：支持打开数据库内容超过 2 GiB 的 .alcd 项目。保存和打开时分块读写
  数据库，避免将完整副本放入内存。数据库快照失败后不再阻止后续保存。保存失败会清理
  临时项目包，启动时也会清理遗留的项目工作目录和数据库快照，并保留正在使用的目录。
