Alcedo Studio 0.3.1（构建 3002）

更新前须知
----------
- 如果 Alcedo Studio 曾在启动后不久或显示几张缩略图后闪退，请不要使用软件内的更新器。
  请从官方网站或 GitHub Releases 下载此构建并手动安装。

导入与项目
----------
- “从文件夹导入”会立即打开文件列表，并在扫描大型文件夹时持续加入文件。导入前、导入中
  和导入后窗口都不再卡住。
- 导入进度会显示预计导入的照片数量，遇到无法导入的文件时该数量会相应减少。非 RAW
  文件显示为已跳过，而不是错误。
- 在欢迎界面切换项目时，窗口不再卡住。

修复
----
- Windows：应用不再在显示两三张缩略图后闪退。此问题影响系统语言为中文或其他非 UTF-8
  编码的系统，以及用户名包含非英文字符的系统。
- Windows：在 Windows 10 1903 及更高版本上，应用现在统一使用 UTF-8 处理文件路径和
  环境变量，在任何系统语言下的行为保持一致。
- 使用 AMD 显卡的 Windows：应用不再在初始化 OpenCL 后端时于启动阶段闪退。镜头校正
  现在可以用 AMD 的 OpenCL 驱动正常编译。
