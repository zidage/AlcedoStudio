Alcedo Studio 0.2.9

新功能
------
- Windows 与 macOS 支持带签名的自动更新。更新按构建号推送，每份更新清单都经过
  签名验证，安装包还会校验平台、来源、大小和内容哈希。
- 设置中新增“更新”页面：显示当前与可用版本、按应用语言显示的发行说明、可取消
  和重试的下载进度，以及无需弹窗的安装与重启操作。
- Windows 与 macOS 均使用原生窗口绘制，系统窗口边框与最小化、最大化、还原等
  行为均由平台原生呈现。
- 导出整体移入检查器，并改为完整的导出方案：编码器、分辨率、EXIF 元数据、ICC
  配置文件、Alpha 通道、文件命名和重名冲突处理。
- 导出会保留 EXIF 元数据，例如评分、拍摄日期、相机、镜头、曝光、焦距和方向；
  写入 EXIF 与嵌入输出 ICC 配置文件均为显式选项。
- 导出文件现在会把 Alcedo Studio 版本写入 EXIF 元数据，并已验证所有受支持导出
  格式的元数据处理。WebP 不再作为导出格式提供。
- 文件名可按模式组合并保存为内联预设：源文件名、拍摄日期、相机、镜头、ISO、
  光圈、快门速度、焦距、评分、固定文字和补零序号。
- 导出尺寸支持原始像素、最长边、像素上限和物理打印尺寸（含 DPI）。Ultra HDR
  与其他导出共用同一尺寸设置并自动执行 8192 像素上限，SDR 与 HDR 的质量设置
  会在会话之间保留。

性能
----
- 尼康 HE/HE* RAW 文件解码速度约为原来的四倍，输出完全一致，Windows 与 macOS
  均可受益。
- macOS 现在以全部核心解码 RAW，并在 GPU 上执行 RAW 处理。开启高光恢复的编辑
  渲染从约一秒降到约 190 毫秒，高光恢复本身从约 581 毫秒降到 53 毫秒。
- macOS 上的交互调整不再每次都缩放预览：整幅缩放从约 60 毫秒降到约 14 毫秒，
  后续调整可直接跳过缩放阶段。

编辑器与图库
------------
- 在图库和编辑器之间切换不再卡住界面。访问图库期间编辑器保持存活，返回时立即
  重新显示。
- 实时调整预览按显示节拍呈现，拖动滑块时会持续显示最新画面，而不是等待下一次
  输入事件。
- 编辑器胶片条与图库使用相同的收藏和筛选结果；当前图片仍在列表中时会保持选中。
- 紧凑的通栏工具栏和收藏卡取代了旧的窗口框架。侧栏在图库中默认展开、在编辑器
  中默认收起并记住选择，右侧按钮分别控制检查器或调整面板。
- 历史记录、版本、调整面板和胶片条使用统一的折叠动画，视图随面板一同伸缩。
- 两个平台均更新了应用图标，Windows 任务栏和安装程序、macOS 的 Dock、Finder
  和安装镜像都会显示新图标。

修复
----
- 粘贴包含 LUT 的调整后，LUT 面板会保持该 LUT 处于选中状态，不再显示为未选择。
- 从欢迎页打开项目不再出现空白框架。
