Alcedo Studio 0.3.3

升级前须知
----------
- 导出现在默认保留原始照片的 GPS 位置。如不需要，可在导出面板中取消勾选“EXIF 中的
  GPS 位置”，或使用“网页”“社交媒体”“电子邮件”预设。
- 导出预设取代了文件名预设。旧版本中保存的文件名预设不会出现在新的预设菜单中。
- 下文的拍摄时间修复只对升级后导入的照片生效。

新功能
------
- AI 智能体可以通过 alcedo-cli 操作 Alcedo Studio。alcedo-cli 现在随应用一起安装在
  程序旁边（macOS 上位于应用包内）。智能体可以打开项目、导入、评分、编辑、生成预览、
  搜索和导出，既可以在没有窗口的独立会话中工作，也可以在你正在使用的窗口中工作。
- 窗口中的智能体：智能体控制期间，你的编辑控件会被锁定，但仍可平移、缩放和查看示波
  器。智能体会话会固定在任务岛和“后台任务”对话框的顶部，并列出它执行的操作。点击
  “停止”会立即收回智能体的控制权。历史记录中会标出智能体所做的编辑，并显示它的备注。
- 导出预设：可选择“标准”“网页”“社交媒体”“电子邮件”“最高质量 JPEG”“16 位 TIFF”
  或“EXR 存档”，也可以保存自己的预设。预设会设置除目标位置以外的所有导出选项。没有
  匹配的预设时，面板显示“自定义”；打开面板时会沿用上次导出的选项。
- 导出元数据：导出面板新增“EXIF 元数据”“ICC 配置文件”和 GPS 位置复选框。JPEG、
  UltraHDR、TIFF、PNG 和 OpenEXR 导出会保留原始照片的 EXIF 和 GPS 数据，但不写入相机
  和镜头序列号。HDR 选项新增最长边设置，范围为 256 到 8192 像素。
- OpenDRT 现在可以为 Rec.709 和 P3-D65 的 sRGB 显示输出渲染。此前这一组合无法渲染。

改进
----
- “全选”（Ctrl+A）会选中当前视图中的所有照片，超过 1,000 张时也是如此。
- 删除照片改为在后台运行，并显示为后台任务，窗口不再因此停止响应。
- 文件夹导入：包含大量 RAW 文件的文件夹导入更快。取消导入现在会很快停止，不再继续
  读取排队中的文件。导入对话框右上角新增关闭（X）按钮用于取消，进度环中显示已导入的
  照片数量。
- 粘贴调整：只粘贴部分调整时，目标照片的其他调整会保持不变。此前它们可能被重置。

修复
----
- RAW 拍摄时间：图库和导出文件现在显示相机时钟的时间。此前时间可能按电脑所在时区的
  偏移量发生偏移，例如在 UTC+9 时区，16:02 会显示为 07:02。
- macOS：修复了打开项目后几秒内、生成 DNG 文件缩略图时可能发生的崩溃。
- macOS：使用 gamma 2.2 或 BT.1886 的 Rec.709 导出现在会嵌入曲线一致的 ICC 配置文件，
  编辑器预览也使用与导出相同的曲线。
- 打开项目时，图库会重新定位到上次编辑的照片。在图库中粘贴调整后，结果提示也会重新
  显示。
- 将最小化的窗口恢复后，编辑器会重新显示当前图像，包括放大视图中的清晰细节。
